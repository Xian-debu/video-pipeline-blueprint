# Third-party notices

This repository is MIT-licensed (see `LICENSE`), but it is not composed from this repository alone:
it installs packages, calls system tools, and (optionally) loads speech models. This file records
every piece that is not ours, with the licence it arrives under, so that anyone deploying the package
knows what they are accepting.

The rule that keeps this file honest is in `docs/engineering-standards.md` §6: **a binary may not
enter `public/` without a row here**, and the row is added in the same commit as the binary.

`docs/design-language.md` was written after reading **ppt-master 6.7.2** (MIT). No SVG, template,

## 6. Adding an asset

1. Confirm the licence allows redistribution (CC0, OFL, MIT, Apache-2.0 with notice — not "free to
   watch" or "for personal use").
2. Media over ~5 MB, or anything that would push a clone past ~100 MB, goes into a release asset;
   the repository keeps only a pointer, a size and a hash.
3. `sha256sum public/<path>` and append a row to §1 in the **same commit** as the binary.
4. If a font, icon set or palette is involved, record the typeface name and weight in the row so a
   future re-render on another machine can be checked against it.
